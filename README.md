## О проекте

QSWM - минималистичный оконный менеджер для Xorg сочетающий в себе базовую функциональность openbox при меньшем объёме кода. Поддерживаемые платформы: Linux, FreeBSD.

## Возможности

**Работа с окнами**
 - Окно на половину экрана: `Win+←` / `Win+→` / `Win+↑` / `Win+↓`
 - Две смежные стрелки до четверти экрана: `Win+←+↑`, `Win+←+↓`, `Win+→+↑`, `Win+→+↓`
 - `Win+Tab` - свернуть все окна разом
 - `Ctrl+Tab` - открепить окно
 - `Alt+Tab` - смена окон

**Горячие клавиши**
[hotkeys] - 6 встроенных действий, по одному биндингу на каждое (повтор строки переопределяет):
 - mod - модификатор для секции (по умолчанию Alt)
 - altTab - оверлей переключения окон
 - close - закрыть окно
 - maximize - развернуть/восстановить
 - minimize - свернуть
 - launcher - запуск launcher_cmd из [general]
 - fullscreen - полноэкранный режим
[exec] - произвольные команды на любых комбинациях.
Пример:
```
mods+клавиша = команда
```

**Настройки внешнего вида: окна, смена окна**
`[appearance]`
- `titlebar_height` - высота заголовка окна, px. Диапазон 8–200
- `button_size` - размер кнопок заголовка (−/□/×), px. Диапазон 4–128
- `icon_left` - иконка приложения слева от кнопок заголовка: `true`/`false`
- `alttab_position` - позиция оверлея Alt+Tab по вертикали: `top`/`bottom`/`center`
- `alttab_icon_size` - размер ячейки/иконки в оверлее Alt+Tab, px. Диапазон 16–256
- `titlebar_color` - цвет заголовка
- `alttab_bg_color` - цвет фона оверлея Alt+Tab
`[icons]`
- `dir` - каталог для иконок программ.


Команды при запуске задаются в `~/.config/QSWM/autostart`
Всё задаётся в `~/.config/QSWM/config.conf` после первого запуска.

## Сборка

**FreeBSD**
```
sudo pkg install xcb-util-keysyms xcb-util-cursor xcb-util-renderutil pkgconf gmake
gmake

./QSWM
```

**Ubuntu/Debian**
```
sudo apt install build-essential pkg-config libxcb1-dev libxcb-keysyms1-dev libxcb-cursor-dev libxcb-render0-dev
make

./QSWM
```
